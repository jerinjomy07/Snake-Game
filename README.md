# Neon Serpent

A touch-first cyberpunk Snake PWA. On a phone, use the neon D-pad or swipe across the game board. On desktop, use Arrow keys or WASD.

## Share through GitHub Pages

1. Create a public GitHub repository and push this folder to its `main` branch.
2. Open the repository’s **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Wait for the **Deploy GitHub Pages** workflow to finish. Its deployment URL is the link to share.

The app works offline after its first successful visit and can be installed using the browser’s **Add to Home Screen** option.
